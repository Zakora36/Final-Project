# Lawfirm Billing System

## Business Problem
Newly established lawfirm needs a more efficent and accurate way to record the their expected billing from clients then using multiple different softwares to record rates and hours and manually adding all the biliing totals together. 

## Business Question
How much gross billable revenue has the firm generated this month, and how does it compare to previous months?

## How to Run
1. Open the project folder in Visual Studio Code.
2. Make sure Python is installed.
3. Run 'main.py'
4. Choose an option from the main menu.
5. Select Save and Exit when finished to preserve your information.

## Menu Options
1. Show Client List
2. Record Transactions
3. Record or Update Billing Rate
4. Show Client Transactions
5. Show Total Hours by Billing Rate
6. Show Monthly Gross Income
7. Start New Month
8. View Previous Month
9. Show Annual Billing Report
10. Run 30-Day Billing Simulation
11. Save and Exit

## Files
- 'main.py' - runs menu
- 'cases.csv' - case data
- 'reports.py' - In progress (report functions)
- 'simulation.py'- In progress (simulation functions)
- 'transactions.csv' - transaction data
